QuickFOV - Minecraft 1.8.9 Forge

Fonction : appuyer sur G active le FOV Quake Pro (110), puis rappuyer sur G restaure le FOV précédent.
La touche est modifiable dans Options > Controls / Contrôles, catégorie QuickFOV.

IMPORTANT : ce ZIP est un projet source, pas encore un .jar compilé.
La compilation automatique est préparée via GitHub Actions dans .github/workflows/build.yml.
Elle utilise Java 8 et Gradle 4.10.3 pour l'ancien environnement Forge 1.8.9.

Dépendance : Minecraft Forge 1.8.9.
Ce build utilise le raccourci natif de Forge, pas l'écran de configuration OneConfig.
